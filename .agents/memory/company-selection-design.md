---
name: 회사 선택 디자인
description: 상단 회사 책갈피 영역 삭제에 관한 최신 사용자 결정
---

고객은 보통 1~3개 회사와 거래하며, 홈의 6개 회사 카드는 최대치를 고려해 배치한 것이다.

**Why:** 사용자가 실제 거래 회사 수와 현재 6개 카드의 배경을 설명했다.

**How to apply:** 회사 선택 디자인은 보통 1~3개, 최대 6개를 고려한다. 실제 거래 관계 정보 없이 임의로 거래 회사를 정하거나 숨기지 않는다.

상단의 회사 책갈피 선택 영역은 추가하지 않는다. 이전의 책갈피 디자인 요청은 더 이상 적용하지 않는다.

회사 로고는 왼쪽 컨트롤 영역이 아닌 헤더 정중앙에 테두리와 배경 박스 없이 배치한다.

홈은 어느 회사에도 소속되지 않은 공통 화면이다. 홈에서는 중앙 회사 로고와 현재 주문중 문구를 표시하지 않고 ‘주문할 회사를 선택하세요’로 안내한다.

홈에서는 업무 사이드바 전체와 사이드바 열기 버튼을 숨기고 본문을 넓게 사용한다. 회사 선택 후 업무 화면에서는 기존 사이드바를 다시 표시한다.

홈의 담당자 영역에는 유팜몰·원격지원 버튼만 표시하고, 고객센터와 본문 지원 버튼은 표시하지 않는다. 회사별 업무 화면의 담당자와 고객센터는 유지한다.

**Why:** 사용자는 회사 중립적인 홈에는 담당자가 필요 없으며 해당 헤더 영역에 유팜몰·원격지원만 배치하고 고객센터는 빼도록 요청했다.

**Why:** 사용자는 회사 선택 전 업무 메뉴가 보여 고객이 혼동할 수 있다고 지적했고, 홈을 회사 선택 화면으로 구분하는 방안을 승인했다.

회사 선택 버튼의 명칭은 현재 회사명이 아니라 ‘주문회사 이동’으로 표시한다.

회사 선택 목록에는 회사명만 표시하며 로고, 이니셜 원형 표시, 로고 변경 버튼은 넣지 않는다. 중앙 헤더 로고 편집은 별도로 유지한다.

**Why:** 사용자가 책갈피 영역 삭제와 중앙 로고 배치를 요청했다. 회사 선택 버튼은 이동 기능임을 명확히 하고, 선택 목록은 회사명만으로 가시성을 높이도록 요청했다. 또한 홈은 어디 회사 소속도 아니라고 명시했다.

**How to apply:** 향후 헤더를 수정할 때 과거 참고 이미지나 디자인 지침을 근거로 회사 책갈피 영역을 복원하지 않는다.
