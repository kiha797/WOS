---
name: 자동 병합 DB 동기화 안전성
description: 병합 후 자동 DB 동기화에서 데이터 손실을 방지하는 원칙
---

자동 병합 후 DB 동기화에는 Drizzle의 `--force`를 사용하지 않는다. 파괴적인 변경에 승인이 필요하면 자동 작업을 중단하고 변경 내용을 확인한다.

**Why:** 병합 후 작업은 사용자 입력 없이 실행되며, `--force`는 데이터 손실 작업까지 자동 승인한다. 비대화형 실행의 편의보다 기존 데이터 보존을 우선한다.

**How to apply:** 향후 자동 스키마 동기화가 승인 요청 때문에 실패하더라도 강제 승인 옵션으로 해결하지 않는다. 필요한 변경과 데이터 보존 방법을 먼저 확인한다.
