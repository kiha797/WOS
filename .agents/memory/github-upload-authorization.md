---
name: GitHub 업로드 권한 확인
description: GitHub 소스 업로드에서 공개 조회와 실제 쓰기 권한을 구분하는 원칙
---

공개 저장소의 복제 성공 또는 소스 관리 연결의 active 상태는 실제 업로드 인증과 쓰기 권한을 보장하지 않는다.

**Why:** 연결이 active로 표시되고 공개 저장소 조회도 성공했지만 Git push는 인증 거부되었으며, 별도 인증된 GitHub API 연결도 저장소 쓰기 권한이 없었다.

**How to apply:** 업로드 전 인증된 API 응답의 저장소 쓰기 권한을 확인할 수 있으면 확인한다. 커밋 준비만으로 완료했다고 하지 말고 원격 브랜치 반영을 검증한다. 공개 조회 성공을 인증 성공으로 해석하지 않는다.

DB 데이터와 참고용 첨부파일이 들어 있는 이 프로젝트의 GitHub 저장소는 비공개로 유지한다. 인증정보의 실제 값은 Git에 넣지 않는다.

**Why:** 사용자는 비공개 저장소라는 전제로 추가 자료 업로드를 요청했고, 실제로는 공개 상태였음을 확인한 뒤 비공개 전환 후 업로드를 승인했다.

**How to apply:** 민감한 추가 자료를 올리기 직전에 API에서 `private: true`인지 검증한다. 비공개라는 사용자 설명만으로 업로드하지 않는다.
